# Hand Gesture Alphabet Recognition

## Overview
This project recognizes hand gesture alphabets using Computer Vision and Machine Learning.

It uses MediaPipe to detect hand landmarks and predicts the corresponding alphabet using a trained machine learning model.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- TensorFlow
- NumPy
- Scikit-learn

## Project Files
- collect_data.py
- create_dataset.py
- train_model.py
- predict.py
- model.pkl
- model.h5
